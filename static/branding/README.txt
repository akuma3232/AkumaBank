PDF BRANDING SLOT
=================

The top-right corner of the first page is reserved for the bank emblem.
It is left blank by default so you can place your own crest from a PDF
reader (or sign the document electronically afterwards).

Optionally, drop the image here and it is placed automatically:

  File name     : emblem.png
  Also accepted : emblem.jpg, emblem.jpeg, emblem.webp, logo.png, logo.jpg, logo.jpeg, logo.webp
  Recommended   : square image, 300x300 px or larger, transparent PNG
  Placement     : top-right reserved area of page 1 (about 118x66 pt)

The file is detected on each generation, so you can drop it in at any
time - no configuration or restart needed.

SIGNATURE
=========
Nothing is printed at the bottom of the page: no signatory name, no
drawn signature and no seal. The lower part of every document is left
free for your electronic signature.
